### 📁 Featured Projects

- 🧠 **[AI Document Q&A Platform](https://github.com/AshwaniPandey0805)**
  - Full-stack MERN single-page application enabling users to upload documents and query them naturally using context-aware LLMs.
  - Implemented an end-to-end **RAG pipeline**: chunking text into embeddings, persisting in vector databases, and retrieving relevant passages to ground LLM responses.
  - Enforced strict schema validation via **Zod** and secure user access with **Firebase / JWT authentication**.

- ⚡ **[Distributed Job Processing & Monitoring Platform](https://github.com/AshwaniPandey0805)**
  - Asynchronous background task execution system built with **Node.js, Express, and Apache Kafka** message broker for heavy tasks (email delivery, report compilation).
  - Integrated automated retry policies for failed jobs and **Redis** for distributed caching and duplicate task prevention.
  - Fully containerized using **Docker** for standardized local development and cloud deployments.

- 🎯 **[Freelance Lead Hunter & Analytics Engine](https://github.com/AshwaniPandey0805)**
  - Automation dashboard built with **React.js & Redux** aggregating freelance project leads via **Apify**, displaying budget, timeline, and requirements in a consolidated interface.
  - Integrated an **LLM layer** to auto-generate customized proposals and analyze win-rate patterns against historical data.
  - Visualized conversion metrics and lead volumes with an interactive **Recharts + MongoDB** analytics dashboard.

- 🛍️ **High-Performance E-Commerce & Mobile API Integrations**
  - Engineered custom checkout extensions, third-party logistics integrations (e.g. InPost lockers), marketplace synchronization (Etsy API), and custom **GraphQL schemas** (Mobikul) delivering fast mobile shopping experiences.
